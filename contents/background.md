## Background and Related Work

These are a few related projects and background sources of information to help us frame our project and build upon similar projects. 



### Fernandes et al. — Predicting Plays in the National Football League

This project uses play-by-play data to predict the outcome of an upcoming play. This project will help us better understand broad data mining methods in the context of our problem. This project gathered data outside of historical performance data and incorporated that into their prediction model. The use of outside data is important in trying to capture the complexity of factors that influence the outcome of a play. This can help us with determining the complexity or rather variety of data needed to accurately predict player outcomes. 


### Mahoney & Paniak — Method and Validation for Optimal Lineup Creation for Daily Fantasy Football Using Machine Learning and Linear Programming

This source provides us with a similar project goal but their only source of data is historical performance data. This will help us understand how historical data can predict players performance and scoring. This project also uses a supervised neural-network which will help us understand what kind of model will work best with our project goal and data. 




### Inside the Huddle: Reproducing ESPN Player Projections Using Public Data

This thesis provides us with an approach to predicting scores using modern machine learning methods and using public data. This is useful for our understanding because it can provide a framework of how to test our model against ESPN's predictions, and with our model selection. This source also helps us with understanding how and what data we have available to us to generate a predictive model.




### Citations

**1. Fernandes et al. — Machine learning for NFL prediction**

This paper is broader than fantasy football, but it is useful for establishing that NFL performance can be modeled using machine-learning techniques. The researchers compared several models for predicting whether an NFL play would be a pass or rush.


Fernandes, C. J., Yakubov, R., Li, Y., Prasad, A. K., & Chan, T. C. Y. (2020). Predicting plays in the National Football League. Journal of Sports Analytics, 6(1), 35–43. https://doi.org/10.3233/JSA-190348

**2. Mahoney & Paniak — Fantasy football prediction**

Mahoney and Paniak specifically developed a neural-network model to predict NFL fantasy points from previous player performance.


Mahoney, J. M., & Paniak, T. B. (2023). Method and validation for optimal lineup creation for daily fantasy football using machine learning and linear programming. arXiv. https://doi.org/10.48550/arXiv.2309.15253

**3. Williams — Princeton thesis**

This is a particularly interesting recent source for your project. Williams' 2026 Princeton thesis uses XGBoost models to predict weekly fantasy performance for running backs, wide receivers, and tight ends using 32,900 player-week observations from the 2022–2025 seasons.


Williams, J. (2026). Inside the huddle: Reproducing ESPN player projections using public data [Senior thesis, Princeton University]. Princeton University. https://theses-dissertations.princeton.edu/entities/publication/d6981488-f30c-47ce-8f06-b6c3e98f2578
